# Sekiclip — product status

**Beta** `0.1.0-beta.1` · offline GUI + CLI · MIT

## Principles

- **Free forever** — no paid plan, no watermarks, no locked export quality.
- **Offline** — media stays on the machine ([PRIVACY.md](PRIVACY.md)).
- **Clear limits** — not a multi-track NLE; see [LIMITS.md](LIMITS.md).
- **Say what ships** — optional hardware features fall back when unavailable.

## Out of scope

Multi-track NLE, color suite, cloud accounts, cloud AI, stream download, DRM, broadcast-certified workflows.

Code signing uses your own certificate (not automated in the build scripts).
