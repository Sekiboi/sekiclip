# Sekiclip 0.1.0-beta.2

Offline media editor for Windows. **Free forever. No uploads.**

## Install

1. Download **`Sekiclip-0.1.0-beta.2-Setup.exe`** (this version — not beta.1)
2. Uninstall any older Sekiclip first if present
3. Run the new installer
4. Open Sekiclip

If Windows shows **“Windows protected your PC”**: More info → Run anyway.

## What’s fixed in beta.2

- **App icon**: multi-size ICO (16–256) + high-res window icon (no more tiny/warped icon)
- **Setup wizard**: branded left-panel logo (classic layout) so the play mark is not elongated
- Same features as beta.1 otherwise
