# Sekiclip 0.1.0-beta.1

Offline media editor for Windows. **Free forever. No uploads.**

## Install

1. Download **Sekiclip-0.1.0-beta.1-Setup.exe**
2. Run the installer (no admin password)
3. Open Sekiclip and drag a file in

Video tools (ffmpeg) are included in this build.

If Windows shows **“Windows protected your PC”** (unsigned beta): More info → Run anyway.

**Portable option:** `Sekiclip-0.1.0-beta.1-portable.zip` — run `Sekiclip.exe` from the folder.

## Highlights

- Preview + timeline In/Out, Play → Out, Loop cut  
- Export quality (resolution + audio kbps)  
- Fades, crop, volume, speed, GIF, logo, burn SRT  
- Convert, compress, extract audio, images, batch  
- Session save/load, recent files, undo/redo  

Preview may look softer than export. **Final quality is the exported file.**

## Privacy

Nothing is uploaded. See [PRIVACY.md](PRIVACY.md).

## Uninstall

Start Menu → Sekiclip → Uninstall, or Settings → Apps → Sekiclip.  
Settings stay under `%LOCALAPPDATA%\Sekiclip` unless you delete that folder.
